Release Vault: Remote-Geräteprofil und Remote-Aufträge löschen

Anbieter: Peter Heinrich. Diese Anleitung betrifft den von Release Vault betriebenen Remote-Unterzeichnungsdienst, nicht Ihre Konten bei Google, Dropbox oder einem Nextcloud-Anbieter.

Löschung in der App

  1. Öffnen Sie Release Vault auf dem Gerät, dessen Remote-Profil Sie löschen möchten.
  2. Öffnen Sie Einstellungen → Remote-Daten.
  3. Lesen Sie die Hinweise und wählen Sie „Remote-Daten löschen“.
  4. Bestätigen Sie die Löschung. Hierfür ist eine Internetverbindung erforderlich.
  5. Nach bestätigtem Servererfolg zeigt die App Datum und Uhrzeit der letzten bestätigten Remote-Löschung an. Diese Anzeige bleibt nach einem Neustart erhalten und bezieht sich auf das damals gelöschte Profil.

Was wird gelöscht – was bleibt erhalten?

Aus der aktiven Remote-Datenbank werden das Geräteprofil, sein öffentlicher Schlüssel und seine Remote-Aufträge einschließlich noch nicht abgeholter Unterschriften entfernt. Die bisherigen Links werden ungültig. Bei einer Löschung in der App wird der zugehörige private Geräteschlüssel nach bestätigtem Erfolg lokal entfernt. Eine externe Browser-Löschung entfernt ihn nicht automatisch vom Gerät.

Lokale Kontakte, Verträge, Unterschriften und PDFs bleiben erhalten. Ein noch nicht abgeschlossener lokaler Vertrag kann danach wieder als Entwurf bearbeitet werden. Andere Geräteprofile und Cloud-Sicherungen werden nicht gelöscht. Eine spätere Remote-Aktivierung ist bewusst erneut möglich.

Exportierte Dateien, Cloud-Dateien, Papierkörbe und Kopien bei Empfängern müssen gesondert gelöscht werden. Diese Funktion löscht sie nicht.

Getrennt aufbewahrte Abschlussnachweise

Nachweise über den Abschluss der Remote-Leistungsbedingungen und gegebenenfalls einer AVV werden getrennt von den Remote-Aufträgen aufbewahrt. Eine Profil-Löschung, App-Deinstallation oder Geräte-Inaktivität entfernt diese Nachweise nicht automatisch. Sie enthalten keine Model-Vertragsinhalte oder Model-Unterschriften.

Ihre Aufbewahrung richtet sich nach dem noch erforderlichen Vertrags-, Nachweis- oder Rechtsverteidigungszweck beziehungsweise einer anwendbaren gesetzlichen Pflicht. Der Bedarf wird mindestens jährlich und bei Vertragsende oder berechtigter Löschanfrage früher geprüft. Eine pauschale unbegrenzte Aufbewahrung gilt nicht. Nach berechtigter Einzelfallfreigabe werden die betreffenden aktiven Nachweiskopien in D1, Versandvermerke, STRATO-Archivnachrichten und manuellen externen Kopien entfernt. Technische Löschsperrvermerke werden gesondert auf ihre Erforderlichkeit geprüft.

Verbleibende technische Speicherfristen

Historische Cloudflare-D1-Datenstände können im derzeitigen Wiederherstellungsfenster von sieben Tagen verbleiben. Wiederholungsschutz-Einträge sind zehn Minuten gültig und werden stündlich bereinigt, regulär spätestens etwa siebzig Minuten nach Erstellung. Tagesbezogene IP-Hash-Ereignisse werden nach 24 Stunden zuzüglich des stündlichen Bereinigungsintervalls entfernt. Technische Ausfälle können die Bereinigung verzögern. Anbieter-Verbindungsprotokolle sind gesondert zu berücksichtigen; ihre vollständige Einordnung ist noch offen.

Kein Zugriff auf das Gerät oder Geräteschlüssel verloren?

Wenn Sie Ihren persönlichen Remote-Löschcode zuvor gesichert haben, öffnen Sie die Remote-Löschseite von Release Vault. Geben Sie dort den Code ein, lesen Sie die Hinweise und bestätigen Sie die Löschung. Der Code erlaubt ausschließlich das Löschen seines Profils, keinen Zugriff auf Vertragsinhalte. Nach erfolgreicher Löschung ist er ungültig.

Den Code erstellen Sie bei aktivem Remote-Zugang unter Einstellungen → Remote-Daten → Persönlichen Remote-Löschcode erstellen. Bewahren Sie ihn sicher außerhalb des Geräts auf. Jeder mit diesem Code kann löschen. Ein neuer Code ersetzt den alten. Beim Kopieren liegt er in der Zwischenablage; fügen Sie ihn ausschließlich an einem sicheren Speicherort ein. Ein bereits verlorenes Gerät kann nicht nachträglich auf diesem Weg abgesichert werden.

Nach einer externen Löschung kann eine vorhandene App noch „Remote offen“ anzeigen. Bei „Status prüfen“ wird der nicht mehr akzeptierte Zugang erklärt. Nach eigener bestätigter Löschung können Sie „Nur lokalen Verweis entfernen“ wählen, um den betroffenen Entwurf wieder lokal zu bearbeiten. Diese Aktion löscht selbst keine Serverdaten. Ein Anmeldefehler allein beweist keine Löschung.

Sie können eine Löschanfrage auch außerhalb der App an releasevault@pitpicture.de senden. Nennen Sie Release Vault und beschreiben Sie, auf welches Gerät beziehungsweise Remote-Profil sich Ihre Anfrage bezieht.

Senden Sie keine Passwörter, privaten Schlüssel, Ausweiskopien oder vollständigen Vertragsbestände unaufgefordert. Vor Herausgabe oder Löschung prüfen wir Berechtigung, Zuordnung und Umfang anhand bereits vorhandener Angaben. Bei begründeten Zweifeln klären wir die Anfrage über einen bereits bestätigten Kontaktweg und nötigenfalls durch angemessene weitere Nachweise. Ausweiskopien werden nicht pauschal verlangt. Postfachzugriff allein belegt nicht unabhängig die Identität oder Vertretungsberechtigung; die bloße Kenntnis einer Gerätekennung oder Vertragsreferenz genügt nicht. Entscheidung, Maßnahme und Ergebnis werden nachvollziehbar dokumentiert. Ohne ausreichende Zuordnung kann kein fremdes Profil gelöscht werden.

Ist der Löschbutton ausgegraut, ist kein nutzbarer Remote-Geräteschlüssel gespeichert. Das ist allein kein Nachweis einer Serverlöschung.
